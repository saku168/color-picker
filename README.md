# Color Picker

A small color picker built with **HTML, CSS and vanilla JavaScript**.

## Features
- Choose a color with the browser's color input.
- Preview the selected color.
- Display its HEX value.
- Copy the HEX value.

## Run locally
1. Clone or download this repository.
2. Open `index.html` in your browser.

No installation or build tools are required.

## Files
- `index.html` — picker interface
- `style.css` — preview and layout
- `script.js` — color value and copy interaction

## What this project practises
Working with input events, strings, and the Clipboard API.
